# Quick Start Guide

## 5-Minute Setup

### Step 1: Install (1 minute)
1. Download this folder
2. Open Chrome
3. Type `chrome://extensions/` in address bar
4. Toggle "Developer mode" ON (top-right)
5. Click "Load unpacked"
6. Select this folder
7. Done! Extension is installed

### Step 2: Test (2 minutes)
1. Go to https://www.instagram.com/instagram/
2. Wait for page to load completely
3. Look for **"📊 Sort by Views"** button (top-right corner)
4. Click it
5. Watch the magic happen!

### Step 3: Use (2 minutes)

**Single Profile:**
- Visit any Instagram profile
- Click the floating button
- Reels sort automatically

**Multiple Profiles:**
- Open 3-4 Instagram profiles in different tabs
- Click extension icon (puzzle piece in toolbar)
- Click "Sort All Instagram Tabs"
- All tabs sort simultaneously

## That's It!

You're ready to sort Instagram Reels by views.

💡 **For multiple tabs:**
- Open profiles in separate tabs (not windows)
- All tabs must be Instagram profile pages

## Common Questions

**Q: Does this work on mobile?**
A: No, Chrome extensions only work on desktop browsers.

**Q: Will Instagram ban me?**
A: No, this only reads public data that's already visible on the page.

**Q: Does it work on private profiles?**
A: No, you can only sort public reels.

**Q: How many reels can it sort?**
A: Typically 50-100 reels per profile (limited by scrolling).

**Q: Does it work on TikTok?**
A: Not yet, but it's planned for future versions.

## Uninstall

1. Go to `chrome://extensions/`
2. Find "Instagram Reels Sorter"
3. Click "Remove"
4. Confirm

## Update

1. Download new version
2. Go to `chrome://extensions/`
3. Click reload icon on the extension card
4. Or remove and reinstall
